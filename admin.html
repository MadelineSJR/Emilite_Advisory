How to apply changes

  1. Make your changes on this page.
  2. Click Download users.js.
  3. On GitHub, open Emilite_Advisory → Add file → Upload files, drop the file in and Commit changes.
  4. Within about a minute, removed or switched-off people can no longer sign in.
