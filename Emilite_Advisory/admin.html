How to apply changes

  1. Make your changes on this page.
  2. Click Download users.js.
  3. On GitHub, open Emilite_Advisory → Add file → Upload files, drop in users.js and Commit changes (it replaces the old one).
  4. Within about a minute, removed or switched-off people are signed out on their next visit.
